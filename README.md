# Python Backend Engineer

I work on the backend side of web applications: APIs, databases, background jobs, and live updates. Python is my main language, with a focus on clear structure and maintainable code.

## How I approach engineering

- **Keep the boundaries clear.** Separate business rules from HTTP, storage, and infrastructure so each part is easier to understand and test.
- **Think beyond the happy path.** Pay attention to permissions, transaction outcomes, and the side effects of a change.
- **Follow the whole workflow.** Connect the request, the data, the background work, and the updates that reach the client.
